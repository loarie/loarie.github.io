Box Turtle Box

A simple simulation of how photo-matching could help identify individual box turtles.

How this works

This is a simple simulation of how you could tell whether two photos show the same individual box turtle, using only the pattern on its shell — like a shell "fingerprint."

1. Load a sample of turtles

Click a point on the map to load real box turtle photos from iNaturalist observations near that spot.

2. Generate control points on each shell

Click Analyze Shells to run every photo through the model. For each photo, it:

  1. Tries to separate the turtle from its background (dirt, leaves, grass, hands) so it isn't distracted by clutter.
  2. Picks out dozens of small, distinctive spots on the shell pattern, called control points. This is the same family of technique used by fingerprint scanners and real animal-ID tools like Hotspotter and WildID.

3. Simulate "uploading" a photo

Once analysis finishes, click any photo to make it the photo you just "uploaded." The app compares its control points against every other photo's control points and counts how many genuinely line up — not just similar-looking, but consistent with the same shell shape seen from two angles. The rest of the photos are then sorted with the closest matches first, and each one shows its matching points count.

4. What's still missing: a threshold

A high match count doesn't automatically mean "same turtle" — that call requires a threshold, a cutoff number of matching points above which you'd confidently say it's a match. Building that threshold for real would mean:

  • Gathering many photo pairs you already know are the same turtle, and many pairs you know are different turtles.
  • Looking at the matching-points count for both groups.
  • Finding a cutoff where same-turtle pairs mostly score above it and different-turtle pairs mostly score below it — for example, "20 or more matching points usually means the same turtle."

That threshold would depend on photo quality, angle, and lighting, and would need testing against real known matches before you could trust it. This simulation stops short of that last step — it shows you the matching in action, but leaves picking the threshold as the open question.
